# PrettyHill

Site da PrettyHill, alojamento local no centro do Porto com dois edifícios, o Almarela (Rua do Almada) e o Belomont6
(Rua de Belomonte): uma página de entrada com todos os apartamentos e uma página própria para três deles.
Site estático (HTML, CSS e JS, sem build): abre `site/index.html` ou publica a pasta `site/`.

- `site/index.html` — a página de entrada: os dois edifícios, o catálogo dos apartamentos e o mapa.
- `site/almarela-1d/`, `site/almarela-com-varanda/` e `site/belomont6-duplex/` — a página de cada apartamento.
- `site/assets/` — estilos, scripts e fotografias.
- `netlify.toml` — publica só a pasta `site/`.

Fotografias da região: Wikimedia Commons (créditos no rodapé do site). Mapas: © colaboradores do OpenStreetMap.
